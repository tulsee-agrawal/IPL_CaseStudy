# Task 1: Total Runs per Match

## Objective
Calculate the total runs scored in each IPL match using NumPy.

## Input
- match_id
- batsman_runs

## Concepts Used
- np.unique()
- Boolean Masking
- np.sum()

## Process
1. Extract match IDs
2. Find unique matches
3. Filter runs for each match
4. Calculate total runs

## Output Example

```python
[(1, 207), (2, 184), (3, 163)]
```

## Learning Outcome
Learned how to perform grouping and aggregation using NumPy without Pandas.
