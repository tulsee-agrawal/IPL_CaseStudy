# Task 2: Top 5 Batters

## Objective
Find the top 5 batters based on total runs scored.

## Input
- batter
- batsman_runs

## Concepts Used
- np.unique()
- Boolean Masking
- np.sum()
- np.argsort()

## Process
1. Find unique batters
2. Calculate total runs for each batter
3. Sort batters by runs
4. Select top 5

## Output Example

```python
[('Virat Kohli', 5878),
 ('Rohit Sharma', 5230)]
```

## Learning Outcome
Learned how to rank and sort data using NumPy.
