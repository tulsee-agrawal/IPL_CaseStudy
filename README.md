
# IPL Dataset Analysis using NumPy

## Overview
This project performs IPL data analysis using only NumPy on the `deliveries.csv` dataset.

The project focuses on:
- Vectorized operations
- Boolean masking
- Aggregation without Pandas
- Real-world structured data analysis

Dataset:
https://www.kaggle.com/datasets/patrickb1912/ipl-complete-dataset-20082020

---

## Technologies Used

- Python
- NumPy

---

## Tasks Performed

1. Total Runs per Match
2. Top 5 Batters
3. Strike Rate Calculation
4. Economy Rate Calculation
5. Runs per Over Analysis
6. Boundary Analysis
7. Death Overs Analysis
8. Highest Scoring Match
9. Runs per Team per Match
10. Match Winner Approximation
11. Match Scorecard Generation

---

## Concepts Used

- NumPy Arrays
- Structured Arrays
- Boolean Masking
- Vectorized Operations
- Aggregation
- Sorting
- Conditional Filtering
