# Task 4: Economy Rate of Bowlers

## Objective
Calculate economy rate for bowlers.

## Formula

```python
Economy = Runs Conceded / Overs Bowled
```

## Input
- bowler
- total_runs

## Concepts Used
- Boolean Masking
- np.sum()
- Counting balls

## Process
1. Calculate total runs conceded
2. Count total balls bowled
3. Convert balls into overs
4. Compute economy rate

## Output Example

```python
[('Bumrah', 6.8)]
```
