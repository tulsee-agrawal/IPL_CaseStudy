# Task 3: Strike Rate of Batters

## Objective
Calculate strike rate for each batter.

## Formula

```python
Strike Rate = (Total Runs / Balls Faced) * 100
```

## Input
- batter
- batsman_runs

## Concepts Used
- np.sum()
- Boolean Masking
- Counting occurrences

## Process
1. Count balls faced by each batter
2. Calculate total runs
3. Apply strike rate formula

## Output Example

```python
[('AB de Villiers', 151.2)]
```

## Learning Outcome
Learned how to combine multiple calculations using NumPy arrays.
